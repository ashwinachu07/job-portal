## Job Application Portal

A Job Application Portal written using HTML, CSS, and JavaScript as frontend with Node.js and Express as backend and MongoDB database.

## How to Run
- Step 1: Clone the repo and open it in any code editor (eg. VSCode)
- Step 2: Open a new terminal in the folder and run `npm install` command
- Step 3: configure the `.env` according to your needs
- Step 4: In the terminal run `node server.js` to start the app
- Step 5: Open any browser and connect to the webpage with the configured port
